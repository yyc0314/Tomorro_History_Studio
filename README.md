# 明日歷史工作室 網站

## 上線步驟（GitHub Pages）

1. repo 設為 Public。
2. 把這個資料夾裡的**全部內容**上傳到 repo 根目錄，包含 assets 資料夾。
3. Settings → Pages → Source 選 "Deploy from a branch"，Branch = main、資料夾 = / (root)，按 Save。
4. 等一到兩分鐘，重整頁面，上方會出現網址：
   https://yyc0314.github.io/<repo名稱>/
